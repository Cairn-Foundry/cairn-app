# v0.3.0 — Editor-First Features

---

## AI Integration

**Inline AI edit**
Select a code range → press a shortcut → type a prompt → agent rewrites the selection in place. The core "human supervises, agent produces" workflow at the line level.

**Send to agent with file context**
Button/shortcut in editor to send current file (or selection) as context to the agent tab, pre-filling the message.

**AI explain selection**
Select code → right-click or shortcut → hover panel explaining what it does. Lighter than a full agent roundtrip.
