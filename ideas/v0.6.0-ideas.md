# v0.6.0 — AI Wrapper Roadmap

## Design principles for this version

- **Claude CLI is the only driver in v0.6**, but the entire architecture is built around a generic `AgentDriver` abstraction — swapping in a new CLI tomorrow requires only a new driver implementation, not touching any UI or store code.
- **Zero-friction onboarding** — a user who just downloaded Cairn should be able to go from zero to a running agent session without leaving the app. That means auto-detecting the CLI, offering to install it, and walking through login entirely inside Cairn.
- **The home screen gains an "AI" section** — login/logout, driver status, and profile management are active/interactive concerns, not passive settings. They live in their own home section, not buried in a settings tab.
